## 1、二叉堆

![[Pasted image 20260428134845.png]]

给定一个 Node 它的索引为 i，则：
```python
PARENT(i)
return [i/2] # 右移一位

LEFT(i)
return 2*i #左移一位

RIGHT(i)
return 2*i + 1 #左移一位再+1
```
### 1.1、最大堆和最小堆
最大堆：`A[PARENT(i)] ≥ A[i]`
最小堆：`A[PARENT(i)] ≤ A[i]`

## 2、保持堆的特性
```python
MAX-HEAPIFY(A, i)
	l = LEFT(i)
	r = RIGHT(i)
	if l < A.heap_size and A[l] > A[i]:
		largest = l
	else
		largest = i
	if r < A.heap_size and A[r] > A[largest]:
		largest = r
	if largest ≠ i
		exchange A[i] with A[largest]
		MAX-HEAPIFY(A, largest)
```
