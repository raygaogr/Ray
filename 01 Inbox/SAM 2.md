## 1、Abstract
**我们提出 Segment Anything Model 2 (SAM 2)，这是一个致力于解决图像和视频中可提示视觉分割的基础模型。我们构建了一个数据引擎，通过用户交互不断改进模型和数据，从而收集了迄今为止最大的视频分割数据集。我们的模型采用了一种简单的 Transformer 架构，并引入流式记忆机制以支持实时视频处理。在我们的数据上训练的 SAM 2 在多种任务中表现出色。在视频分割任务中，我们的方法仅需前人方法 1/3 的交互次数即可实现更高的准确性；在图像分割任务中，我们的模型不仅更准确，且速度比原始 Segment Anything Model (SAM) 快 6 倍。我们相信，我们的数据、模型和见解将成为视频分割及相关感知任务的重要里程碑。我们已开源模型、数据集和交互式演示。**
## 2、Promptable Visual Segmentation (PVS)
PVS 任务允许在视频的任意帧上向模型提供提示。提示可以是正向/负向的 points、boxes 或 masks，既可用于定义待分割的对象，也可用于优化模型已预测的对象。为实现交互式体验，当模型接收到某一特定帧的提示后，应立即生成该帧上物体的有效分割掩码。在接收初始提示（一个或多个，可位于同一帧或不同帧）后，模型需传播这些提示，以在整个视频中生成目标物体的 masklet（即“时空掩码”），其中包含物体在每一帧的分割掩码。用户可在任意帧上提供额外提示，以在整个视频中持续优化分割结果。

## 3、Model
SAM 2 配备了一种内存机制，用于存储目标物体的信息和历史交互记录，这使其能够在整个视频中生成 masklet（时空掩码）预测，并基于从已观测帧中存储的物体上下文记忆，对这些预测进行高效修正。流式架构是 SAM 在视频领域的自然扩展：逐帧处理视频帧，并配备内存注意力模块以关联目标物体的历史记忆。当应用于图像时，内存为空，模型行为与 SAM 一致。

### 3.1、Image Encoder
图像编码器在整个交互过程中仅运行一次，其作用是为每一帧提供非条件标记（特征嵌入）。SAM 2 使用基于 MAE 预训练的 Hiera 图像编码器，该编码器具有层次化结构，使在解码过程中能够使用多尺度特征。
### 3.2、Memory Attention
内存注意力的作用是使当前帧特征能够基于过去帧的特征、预测结果以及任何新输入的提示信息进行条件化处理。SAM 2 堆叠了 L 个 Transformer 模块，其中第一个模块以当前帧的图像编码作为输入。每个模块依次执行自注意力操作，随后通过交叉注意力机制关注存储在 Memory Bank 中的（提示/未提示）帧记忆和 Object Pointer，最后通过一个多层感知机（MLP）进行处理。SAM 2 采用原生注意力操作实现自注意力和交叉注意力，这使能够利用高效注意力内核（Flash-Attention）的最新进展。

### 3.4、Mask Decoder
和 SAM 的 mask decoder 大部分都相同，不同之处在于：
1. SAM 2 解码器使用的帧嵌入并非直接来自图像编码器，而是**基于过去预测的记忆和提示帧**生成的。值得注意的是，提示帧可以是相对于当前帧的“未来帧”（即后续帧）。
2. SAM 在给定一个 positive prompt 的条件下总是会生成一个有效目标的 mask，而对于 PVS 任务，是可能存在无有效目标的情况的，因此新增了一个 head 用来预测目标是否出现在当前帧中。
3. decoder 还会接收一些 image encoder 直传进来的 feature 特征用来产生高分辨率的信息。
**Object pointer token:**  用 output mask token 来赋值。

### 3.5、Memory Encoder
内存编码器通过使用卷积模块对输出掩码进行下采样，并将其与图像编码器提供的非条件帧 Embedding 进行逐元素求和，随后通过轻量级卷积层实现信息融合，从而生成内存特征。
### 3.6、Memory Bank
Memory Bank 通过维护两个先进先出队列来保留视频中目标物体的历史预测信息：其一存储最多 N 帧的近期 Memory 特征（未提示帧），其二存储最多 M 帧的提示记忆（来自用户交互）。例如在视频目标分割（VOS）任务中，当初始掩码是唯一提示时，Memory Bank 会持续保留首帧记忆以及最多 N 帧的近期记忆。这两类记忆均以空间特征图的形式存储。

除了空间记忆模块，SAM 2 还基于每帧的掩码解码器输出 tokens 将用于表征目标物体高层语义信息的 object pointers 存储为轻量级向量。SAM 2 的内存注意力机制同时对空间特征图和 object pointers 进行 cross-attention。SAM 2 向 N 帧近期记忆中嵌入时间位置信息，使模型能够表征短期物体运动特征，但未对 prompt frame 进行时间编码。这是因为 prompt frame 的训练信号较为稀疏，且在推理阶段可能出现与训练时时间分布差异较大的提示帧，此时难以进行有效泛化。
## 4、Data Engine
SAM 2 采用了一个数据引擎，通过将模型与标注员结合使用，交互式标注新数据和具有挑战性的数据，从而生成训练数据。与大多数现有视频分割数据集不同，SAM 2 的数据引擎不限定目标物体的类别，而是旨在为分割任何具有有效边界的物体（包括部件和子部件）提供训练数据。相比现有基于模型辅助的方法，SAM 2 的数据引擎在质量相当的前提下，效率提升了8.4倍。最终的Segment Anything Video（SA-V）数据集包含 5.09  万个视频中的 3550 万条掩码，是现有视频分割数据集掩码数量的 53 倍。SA-V 数据集具有挑战性，包含视频中频繁遮挡和重现的小物体及部件。
### 4.1、阶段 1：逐帧 SAM 处理
初始阶段采用基于图像的交互式 SAM 模型辅助人工标注。标注人员需以每秒 6 帧（FPS）的速度，通过 SAM 模型逐帧标注视频中目标物体的掩码，并结合像素级精确的手动编辑工具（如“画笔”和“橡皮擦”）进行修正。此阶段**未引入跟踪模型**辅助掩码在时间维度上的传播。由于这是逐帧标注方法且每帧需从零开始标注，标注过程较慢，实验中平均每帧耗时 37.8 秒。但此方法能够生成高质量的逐帧空间标注。在此阶段，我们共在 1400 个视频中收集了 1.6 万个“masklet”（局部掩码片段）。我们进一步利用此方法标注 SA-V 验证集和测试集，以避免 SAM 2 模型在评估时可能引入的偏差。
### 4.2、阶段 2：SAM + SAM 2 Mask
第二阶段引入了 SAM 2 模型，其仅接受掩码作为提示（prompt）。将此版本称为 **SAM 2 Mask**。标注人员沿用阶段 1 的 SAM 工具和其他手动工具（如画笔/橡皮擦），在首帧生成空间掩码后，通过 SAM 2 Mask 将标注掩码**时间传播**到其他帧，从而获得完整的时空 masklet 。在后续任意帧中，标注人员可通过在当前帧**从零标注新掩码**（使用SAM、画笔和/或橡皮擦），并利用 SAM 2 Mask 重新传播，迭代修正预测结果，直至 masklet 准确无误。SAM 2 Mask 的初始训练基于阶段 1 数据及公开数据集。在阶段 2 中，利用收集的数据**在标注循环中两次重新训练并更新SAM 2 Mask**。此阶段共收集了6.35 万个 masklet，标注效率提升至 7.4 秒/帧，较阶段 1 提速约 5.1 倍。尽管标注速度显著提升，但这种**解耦式方法**仍需在中间帧从头标注，缺乏历史记忆支持。最终，我们开发了全功能版 SAM 2，实现了交互式图像分割与掩码传播的统一建模。
### 4.3、阶段 3：SAM 2
在最终阶段，我们采用功能完善的 SAM 2 模型，其可接受多种类型提示（如点和掩码）。SAM 2 通过跨时间维度的目标记忆生成掩码预测，这意味着标注人员只需在中间帧向 SAM 2 提供**少量修正点击**（occasional refinement clicks），即可编辑预测的masklet，而无需像传统空间 SAM（仅基于单帧且无时间记忆）那样从零标注。在阶段 3 中，我们利用收集的标注数据**对 SAM 2 进行了五次重新训练与更新**。随着SAM 2 的引入，单帧标注时间**降至 4.5 秒**，相比阶段 1 提速约 **8.4倍** 。此阶段共收集了 **19.7 万个 masklet**。
