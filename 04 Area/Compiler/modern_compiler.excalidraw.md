Compile Pipeline ^H3OPBPUp

1. Source code 解析成surface language
2. Surface language 翻译成core language
3. Core language 使用core-to-core的transformation进行优化，
  可能使用e-graph工具
4. Core language lower into MLIR
5. MLIR 执行high-level的优化
6. MLIR lower into LLVM IR
7. LLVM IR 执行low-level 优化，并进行代码生成 ^j9R1DEMY
