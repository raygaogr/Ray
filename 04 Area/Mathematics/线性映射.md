## 映射
集合 A、B，映射 $f: A \rightarrow B$
                $\forall a  \rightarrow \exists b = f(a) , a\in A, b\in B$
其中，$\mathcal{Im} f = f(A) = \{f(a)|a\in A\}$ 称为映射 $f$ 的像集
如果，$\mathcal{Im}f = B$ 称为满射
如果，$a_1 \neq a_2，则 f(a_1) \neq f(a_2)$ 称为单射
如果映射既为满射又为单射，称 $f$ 为双射
设 $f,g A\rightarrow B$ 映射，$f=g \iff \forall a \in A, f(a) = g(a)$ 
$f: A \rightarrow B, g: B\rightarrow C$ 映射的复合定义为
$g\circ f : A\rightarrow C, \forall a\in A, g\circ f(a) = g(f(a))$
## 线性映射
设 $V, U$ 是数域 $K$ 上的线性空间，$\phi: V \rightarrow U$，如果 $\forall \alpha,\beta \in V, k\in K$ 满足：
- $\phi(\alpha + \beta) = \phi(\alpha) + \phi(\beta)$
- $\phi(k\alpha) = k\phi(\alpha)$
则称 $\phi: V\rightarrow U$ 为线性映射，$\phi: V\rightarrow V$ 为线性变换
如果 $\phi$ 为双射，则称 $\phi: V \rightarrow U$ 为线性同构，记为 $V \cong U$
### 命题 1
设 $\phi: V\rightarrow U$ 为线性映射，则
（1）$\phi(0_v) = 0_u$
$\phi(0_v) = \phi(0_v + 0_v) = \phi (0_v) + \phi (0_v) \Rightarrow \phi(0_v) = 0_u$
  (2) 若 $\phi : U \rightarrow V$ 是线性同构，则 $\phi ^{-1}: U \rightarrow V$ 也是线性同构
  $\forall t,s \in U, k,l \in K$
  $\phi(\phi^{-1}(kt + ls) - k\phi^{-1}(t) - l\phi^{-1}(s)) = kt + ls - kt - ls = 0_u$  
  $\Rightarrow \phi^{-1}(kt + ls) - k\phi^{-1}(t) - l\phi^{-1}(s) = 0_v$
  $\Rightarrow \phi^{-1}(kt + ls) = k\phi^{-1}(t) + l\phi^{-1}(s)$
  (3) 设 $\phi: V\rightarrow U$ 为线性映射（同构），$\psi: U \rightarrow W$ 为线性映射（同构）则
  $\psi \circ \phi : V \rightarrow W$ 也是线性映射（同构）
    $\forall \alpha, \beta \in V, k,l \in K$
    $\psi \circ \phi (k\alpha + l\beta) = \psi(k\phi(\alpha) + l\phi(\beta)) = k\psi\phi(\alpha) + l\psi\phi(\beta)$
   
### 推论 1
线性同构是**等价关系**
### 定义 1
设 $V,U$ 是 $K$ 上线性空间，记 $\mathcal{L}(V, U)$ 为 $V \rightarrow U$ 线性映射全体，$\forall \phi,\psi \in \mathcal{L}(V, U)$ 定义加法 $(\phi + \psi)(\alpha) = \phi(\alpha) + \psi(\alpha)$
则 $\phi + \psi$ 是线性映射
$(\phi + \psi)(\alpha + \beta) = \phi(\alpha + \beta) + \psi(\alpha + \beta) = \phi(\alpha) + \phi(\beta) + \psi(\alpha) + \psi(\beta) = (\phi + \psi)(\alpha) + (\phi + \psi)(\beta)$
定义数乘 $(k\phi)(\alpha) = k\phi(\alpha)$
$(k\phi)(\alpha)=k\phi(\alpha)=\phi(k\alpha)$
### 定理 1
$\mathcal{L}(V, U)$ 在上述加法和数乘下成为 $K$ 上线性空间，
对于 $\mathcal{L}(V)$，在上述加法和数乘的基础上再定义乘法 $\psi\circ\phi: V\rightarrow V$
则 $\mathcal{L}(V)$ 成为数域 $K$ 上的代数

## 线性映射与矩阵
### 定理 1（线性映射存在性定理）
设 $V, U$ 是数域 $K$ 上的线性空间，$\{e_1,e_2,...,e_n\}$ 是 $V$ 上的一组基，$\{\beta_1,\beta_2,...,\beta_n\}$ 是 $U$ 中任意一组向量，则存在有**唯一的**映射 $\phi: V \rightarrow U$ 并令 $\phi(e_i) = \beta_i, 1\leq i\leq n$ ，则 $\phi$ 是一个线性映射。

**存在性** 因为 $\phi$ 在基向量上取值已确定，所以可以线性扩张到整个空间 $V$ 上：
$\forall \alpha \in V, \alpha = \lambda_1e_1 + \lambda_2e_2 +...+\lambda_ne_n$
根据定义 $\phi(\alpha) = \lambda_1\beta_1 + \lambda_2\beta_2 +...+\lambda_n\beta_n$
$\Rightarrow \phi: V\rightarrow U$ 是映射
任取 $\gamma \in V, \gamma = b_1e_1 + b_2e_2 +...+b_ne_n$
$\alpha + \gamma = (\lambda_1+b_1)e_1 + (\lambda_2+b_2)e_2 +...+(\lambda_n+b_n)e_n$
$\phi(\alpha + \gamma) = \phi((\lambda_1+b_1)e_1 + (\lambda_2+b_2)e_2 +...+(\lambda_n+b_n)e_n)=(\lambda_1+b_1)\beta_1 + (\lambda_2+b_2)\beta_2 +...+(\lambda_n+b_n)\beta_n$
$\Rightarrow \phi(\alpha + \gamma) = \phi(\alpha) +\phi(\gamma)$
### 定义 1
设 $\phi: V^n \rightarrow U^m$ 的线性映射，取 $\{e_1,e_2,...,e_n\}$ 为 V 上的一组基，$\{f_1,f_2,...,f_m\}$ 为 U 上的一组基，则
$\phi(e_1) = a_{11}f_1 +...+a_{m1}f_m$
$\phi(e_2) = a_{12}f_1 +...+a_{m2}f_m$
$\phi(e_n) = a_{1n}f_1 +...+a_{mn}f_m$
$(\phi(e_1),\phi(e_2),...,\phi(e_b)) = (f_1, f_2,...,f_m)A$
则称矩阵 $A$ 为 $\phi$ 在给定基下的表示矩阵
任取 $\alpha \in V$ ，$\alpha = \lambda_1e_1 + \lambda_2e_2 +...+\lambda_ne_n \iff (\lambda_1, \lambda_2,..., \lambda_n)$ 坐标向量
则 $\phi(\alpha) \in U$ ，$\phi(\alpha) = \mu_1f_1 + \mu_2f_2 +...+\mu_mf_m \iff (\mu_1,\mu_2,...,\mu_m)$ 坐标向量
$\Rightarrow A(\lambda_1, \lambda_1, ...,\lambda_n) = (\mu_1,\mu_2,...,\mu_m)$
